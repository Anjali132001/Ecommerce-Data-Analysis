E-commerce Data Analysis Using SQL

Project Overview
This project focuses on analysing e-commerce data using SQL to uncover insights into customer behaviour, product performance, sales trends, 
and marketing effectiveness.
The analysis uses four relational tables: Customers, Products, Orders and OrderDetails. 
SQL queries are used to answer business questions and support data-driven decision-making.

Business Objectives
- Identify cities with the highest number of customers.
- Analyse customer ordering frequency and shopping behavior.
- Evaluate product performance using quantity and revenue metrics.
- Identify product categories attracting the most unique customers.
- Analyse month-wise sales trends and changes in average order value.
- Explore customer acquisition trends and potential marketing opportunities.

Dataset Description
The Project uses four CSV files:

  File                  Description
Customer.csv            Customer information and location
Products.csv            Product details and categories
Orders.csv              Customer orders and order dates
details.csv             Products, Quantities, and prices associated with orders

Tools & Technologies
- MySQL Workbench - Writing and executing SQL queries
- SQL - Joins, aggregate functions, subqueries, Group by, Having, and window functions

Analysis Performed
1. Customer distribution by location
2. Customer order frequency analysis
3. Product-level quantity and revenue analysis
4. Category-wise unique customer analysis
5. Monthly sales and sales-change analysis
6. Average order value trends
7. Product sales frequency and customer visiblity
8. First-purchase month and new customer trends
9. Identification of top-performing sales months

Business Value
The analysis can help an e-commerce business:
- Understand customer purchasing patterns.
- Identify products and categories worth investigating for growth.
- Monitor monthly sales performance.
- Discover opportunities to improve customer acquisition and marketing.
- Make more informed business decision using data.
