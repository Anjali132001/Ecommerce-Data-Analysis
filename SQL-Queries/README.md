SQL queries and solution for the E-Commerce Data Analysis project.
Overview 
This folder contains SQL queries used to solve business questions for the E-commerce Data Analysis project.

Objectives
- Analyse customer and order data.
- Identify top-selling products.
- Analyse sales and order trends.
- Understand customer purchasing behavior.
- Solve business questions using SQL.

  Tools Used
  - MySQL Workbench
  - SQL

  Files Included
  - E-commerce_Analysis.sql - Contains SQL queries and solutions for the project problem statement.

  Analysis Approach
  1. Understand the problem statement.
  2. Explore the e-commerce database tables.
  3. Write SQL queries to answer business questions.
  4. Execute queries in MySQL workbench.
  5. Review the results and identify insights.
